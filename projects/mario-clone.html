SDL2 Mario Clone

Pure C++ • SDL2 Library • 2D Framework Design

Project Overview

A technical recreation of the classic Super Mario Bros. level 1-1 built from scratch using pure C++ and the SDL2 library. This project focuses on manual implementation of engine fundamentals, including custom rendering, physics, and tilemap systems without the aid of a commercial game engine.

Technical Highlights

  • Engine Fundamentals: Built a custom game loop managing event handling, updates, and rendering at 60 FPS.
  • Physics & Collision: Implemented AABB collision detection and gravity-based physics for player and enemy movement.
  • Tilemap System: Developed a manual sprite-sheet slicing and tile-based rendering system for level construction.
  • Animation Logic: Created a state-driven animation controller for character walking, jumping, and interaction states.
  • Pure C++: Managed memory and resource loading (textures, sounds) using SDL_image and SDL_mixer.
