Platform Knight

2D Action Platformer • Unity • C#

Project Overview

Platform Knight is a classic 2D side-scrolling prototype developed to master the fundamentals of character controller design and environmental interaction. The focus was on creating "juicy" movement and reliable collision detection within a standard platforming framework.

Project Highlights

  • Character Controller: Implemented responsive movement logic including variable jump heights and coyote time.
  • Combat Mechanics: Developed a melee attack system with hitbox detection and enemy knockback effects.
  • Environmental Hazards: Created reusable prefabs for spikes, moving platforms, and falling obstacles.
  • State Machine: Utilized a simple Finite State Machine (FSM) to manage player animations (Idle, Run, Jump, Attack).
  • Level Design: Designed a vertical level layout to test mechanical skill and player progression.
